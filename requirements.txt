# 2026-09-18: 프로젝트 가상환경(.venv, Python 3.11) 패키지 전체 목록 (uv pip freeze)
#
# 설치 방법:
#   uv venv --python 3.11 .venv
#   uv pip install --python .venv/Scripts/python.exe torch --index-url https://download.pytorch.org/whl/cu128
#   uv pip install --python .venv/Scripts/python.exe -r requirements.txt
#
# 주의:
# - torch(2.11.0+cu128, CUDA 12.8 빌드)는 PyPI가 아니라 https://download.pytorch.org/whl/cu128 에서 받아야 하므로,
#   위처럼 torch만 먼저 --index-url로 설치한 뒤 나머지를 설치한다.
# - GPU별 안내:
#   * RTX 50 시리즈(Blackwell, 이 개발 컴퓨터의 RTX 5060): 반드시 cu128 이상 필요 (cu126 이하는 아키텍처 미지원).
#   * RTX 40 시리즈(Ada Lovelace) 등 그 이전 세대: cu128로도 문제없이 동작한다 - 이 태그는 "이 GPU 세대 전용"이 아니라
#     "이 빌드가 지원하는 최신 CUDA 툴킷 버전"이며 이전 세대 GPU와도 호환된다. 다만 cu128은 비교적 최근 NVIDIA
#     드라이버(2025년 초 이후)가 필요하므로, 만약 드라이버가 오래돼 GPU 인식에 실패하면 아래처럼 cu126으로 대체한다:
#       uv pip install --python .venv/Scripts/python.exe torch --index-url https://download.pytorch.org/whl/cu126
#   * GPU가 없거나 CPU만 쓸 경우: --index-url 없이 `pip install torch`로 대체 가능.
#   * 설치 후 `python -c "import torch; print(torch.cuda.is_available())"`로 GPU 인식 여부를 꼭 확인한다.
# - KoNLPy(Okt)는 JVM이 필요하다 (Java/OpenJDK 설치 필요, pip만으로는 해결되지 않음).
# - 한글이 포함된 matplotlib 플롯을 그리려면 Windows의 맑은 고딕(Malgun Gothic) 폰트가 필요하다 (OS 기본 제공).
